# yt-script — YouTube script development

## Purpose
Create a spoken, retention-aware script for AI Tech Safar.

## Inputs
Topic, target viewer, video length, primary sources, desired format and call to action.

## Workflow
1. Define one viewer problem and one promised outcome.
2. Identify what is genuinely new or useful; reject generic AI hype.
3. Open with a specific outcome, surprising fact or costly mistake. Avoid greetings and channel introductions.
4. State the context quickly, then structure the body into clear escalating sections.
5. Add examples, demonstrations and transitions. Mark any claim that needs verification as [VERIFY].
6. End with a concise recap and one relevant CTA.

## Output
Title premise, hook, full spoken script, on-screen visual notes, source list, [VERIFY] claims and estimated runtime.

## Quality gate
No invented statistics, fake quotes, unsupported superlatives or misleading promises. Read aloud and remove filler.
